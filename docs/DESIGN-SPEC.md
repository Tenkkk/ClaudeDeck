# ClaudeDeck 界面规格

> **这份文档描述界面现在是什么样,以及为什么是这样。**
>
> 它有两个用途:一是回归基准 —— 界面变了而这里没变,就是其中一方错了;
> 二是新人入门,把「为什么这么画」一次讲清,免得每处都要去翻 git log。
>
> 它不再是给设计工具的任务书。要重绘视觉时,这份现状仍是最准的输入;
> 想加新东西请另开文档,不要在这里写「将来应该」。

---

## 0. 产品一句话

把命令行工具 **Claude Code** 装进窗口的 Windows 桌面客户端。

用户在这里跟 Claude Code 对话、切换模型与努力程度、逐次批准工具调用、
回到任何一次历史会话,并顺手改这个项目的 `.claude` 配置。

**设计语言**:Organic。
**目标气质**:像一个安静的写作工具,不像开发者控制台。用户在这里说话,不在这里看日志。

本轮整体视觉参考 [Claude 官方桌面教程](https://claude.com/resources/tutorials/navigating-the-claude-desktop-app)的公开首页截图:暖灰画布、克制图标、圆角输入卡、衬线标题。只借鉴视觉语言,保留 ClaudeDeck 品牌与项目结构,不冒充官方客户端或增加无功能标签。具体颜色是本项目适配值,并非声称提取了官方设计 token。

## 1. 画布与全局

| 项 | 值 |
|---|---|
| 平台 | Windows 10 / 11 |
| 默认窗口 | 1200 × 800 |
| 最小窗口 | 940 × 600 |

| 主题 | 亮色与深色**同等地位**,见 §9 |

### 布局骨架

```
┌───────────────────────────────────────────────────────────┐
│ ⊞ ⌕ ⚙                                          ─  □  ✕    │ ← 标题栏 34px
├──────────────┬────────────────┬───────────────────────────┤
│ 侧栏          │ 对话主区        │ 文件区(可选)              │
│ 264px         │ 剩余            │ 默认 480px                │
│ 可拖 200–420  │ 至少 360        │ 可拖 240–960              │
└──────────────┴────────────────┴───────────────────────────┘
```

两道竖线都可拖拽调宽,各有上下限,并且**始终给主区留出 360px**。
宽度记在 `localStorage`(渲染层的视觉偏好,不进 `config.json`)。
侧栏可整列收起,收起时栅格直接去掉那一列 —— 不是把宽度归零,
归零的话里面的内容还在,照样参与布局计算。

## 2. 屏幕与覆盖层

**四个屏幕**,按启动时的判定顺序:

```
启动
 └─ 环境检查 ────────────────► A 加载
     ├─ 找不到 Claude Code ──► B 首次配置
     ├─ 没选过项目 ──────────► C 选择项目
     └─ 都就绪 ──────────────► D 主界面
```

前三屏也带那条自绘标题栏,只是左侧的三颗按钮不出 —— 无边框窗口如果某一屏
没有标题栏,那一屏就连关闭按钮都没有,只能去任务管理器结束进程。

**覆盖层**(浮在主界面之上,不算屏幕):搜索面板、系统设置、外观与账号浮窗、
分支确认、会话右键菜单、控件条的三个弹层、命令面板。

### 系统设置面板

使用原生模态对话框,最大宽 780px、高度不超过窗口减 48px;左侧 176px 暖灰分类栏,右侧内容与固定底栏,低高度只滚动内容。小于 640px 时分类横排。默认“连接配置”,另有“运行环境”“关于与更新”,仅复用已有功能。

连接字段使用上方标签与整行输入,密钥仅展示保存状态;技术细节用可展开说明。底栏提供保存、清除密钥与状态反馈,不把更新按钮混入表单。运行环境展示实际 CLI 状态/版本/来源,长路径放入详情、错误显式展示。关于页保留主动检查/下载/重启安装与进度状态。切换分类不丢草稿,背景不可交互,关闭按钮/Esc/遮罩关闭后焦点回到原入口;保存失败可重试。沿用全局主题及可访问文字对比度,不改主进程接口。

## 3. 屏幕 A / B / C

这三屏是一次性的,配置完就再也看不到,所以只记要点。

**A 加载** —— 居中一行 `正在检查运行环境…`,上方一颗 2.4s 呼吸的品牌点。
不用转圈:转圈暗示「可能很久」,而这一屏通常不到 1 秒。

**B 首次配置** —— Claude Code 的四种状态(检测中 / 可用 / 缺失可一键安装 / 安装失败),
安装过程的等宽日志区,以及可选的 API 端点与密钥。
密钥经 `safeStorage` 加密落盘,界面上有一句说明它不存明文。

**C 选择项目** —— 最近项目列表 + `添加项目…` 主按钮。
路径按 §10 的规则截断:保留盘符与末两级,中间用 `…` 顶掉。
项目分组只保留添加加号,不设置“管理项目”入口;编辑与移除走项目右键菜单。加号与首次选择页添加按钮打开“创建项目”弹窗:顶部标题和关闭按钮,带文件夹图标的名称输入框,源文件夹选择区域,底部取消与创建按钮。未选择时展示“在此电脑上添加文件夹”和添加按钮,选择后展示目录及更换按钮;不设置无功能的来源下拉。沿用主题变量,最大宽度 640px,窄窗口自适应,亮暗主题一致。目录必填,名称选填,占位提示“项目名称（选填,默认使用文件夹名）”;名称留空或只有空白时用文件夹名称,不将默认值强制写入输入框,更换目录后采用最新所选目录的名字。选择目录后即可创建,提交禁重复,错误在表单内展示;系统选择器仅选择目录,确认创建才登记。弹窗不卸载工作区,取消不新建会话或丢弃草稿;支持关闭按钮、Esc、遮罩、焦点闭环及返回添加入口。最后一个项目移除后仍回到独立选择页。

## 4. 标题栏

高 34px,整条是拖拽区(`-webkit-app-region: drag`),按钮各自 `no-drag` ——
不单独标的话按钮会被拖拽区吃掉点击。

| 位置 | 内容 |
|---|---|
| 左 | 侧栏开关、搜索、系统设置 |
| 中 | **空着** |
| 右 | 最小化、最大化 / 还原、关闭 |

**中间为什么空着:** 当前会话标题在归属行已经有了,标题栏再写一遍就是同一句话
占两行;空着也让整条更好拖。

**底色取侧栏那一色**,两套主题都走同一个变量,且**不画分隔线** ——
无边框的目的就是让它和下面成为一整块,一条横线会把它重新切回「系统的那条」
和「应用画面」两截。

关闭是唯一一颗悬停变红的:它和另外两颗的后果不是一个量级。

## 5. 侧栏

```
ClaudeDeck                          ← 品牌行
项目 · 3          ···   ＋           ← 分组头
  ▾ 📁 ClaudeDeck    8   ✎
      › 📁 文件
        会话标题
        18:44 · main
      ⋯
      展开全部 8 条 / 收起
  › 📁 Downloads      4   ✎
─────────────────────────────
额度      5 小时 65% │ 7 天 20%     ← 底部
0.2.1 · CLI 2.1.220 · $0.31    ☀
```

**品牌行**:仅显示 `ClaudeDeck`,不设置重复的全局“新建会话”按钮。
新建会话使用目标项目行右侧的铅笔图标,保留原有项目归属与后台执行行为。

**项目 → 会话两层**。每个项目行有折叠箭头、文件夹图标、会话计数,
以及一颗悬停/键盘聚焦时显示的铅笔图标(在这个项目里新建会话)。
项目分组的添加加号也只在分组行悬停/键盘聚焦时显示。加号与铅笔采用 18px SVG 和 32px 点击区域,右侧边缘对齐,中性颜色、悬停浅底;隐藏时保留占位且不接收鼠标点击,Tab 可聚焦并显示轮廓,触屏保持可见。尊重减少动态效果设置。
文件入口是项目行右侧的文件夹图标,与铅笔并列;项目下面只列会话,不再插入独立的“文件”行。
图标在项目行悬停或键盘聚焦时显示,文件区打开时常显高亮;隐藏时保留占位,不造成名称和计数跳动。带可访问名称与打开状态,项目折叠时仍可操作。

项目行右键(或 Shift F10 / 菜单键)打开“编辑项目”“移除项目”,沿用会话菜单弹层样式,不触发折叠或切换会话。菜单支持上下键、首尾键及 Esc,关闭后焦点回到项目行;弹层按实际尺寸避开窗口边缘。
编辑面板包含名称输入与只读目录,空白名称不能保存;仅更新显示名称。移除使用二次确认,明确“不删除目录或历史,但会停止该项目运行任务”。有未保存文件时阻止移除并提示保存或关闭;提交中禁止重复操作,失败保留面板并显示原因。
移除当前项目后进入剩余项目的新会话,移除最后一个项目进入选择页;非当前项目移除不影响当前对话。原项目行已移除时,焦点交给剩余项目行或选择页的添加按钮。

默认只显示最近 3 条会话,`展开全部 N 条` 展开,**同一颗按钮可以收回去**。

**当前会话**使用较深的中性选中底与加粗标题,不再画陶土竖条;与浅一档的悬停底区分。项目、会话与分组使用 UI 字体,减少装饰字距。

**底部**:额度两档(拿不到就整块消失,见 §9)、版本与本会话花费、
以及一颗管**外观与账号**的按钮(主题三选一、邮箱 / 组织 / 订阅、版本)。
那颗按钮画的是半日半月,不是齿轮 —— 齿轮读作「系统设置」,而系统设置在标题栏。

**发出消息的那一刻**这条会话就要出现在列表里,不等这一轮答完。
标题由 Claude 生成、会晚一点变,本轮结束时刷新盖上去。

## 6. 文件内容区(右栏)

点侧栏项目行右侧的文件夹图标或归属行右端的「文件」打开。两级形态:

**文件树** —— 一次只列一层。展开哪层问哪层,不做一次性递归:
遇到 `node_modules` 就是几十万个条目,界面直接没了。
`.claude` 只是树里的一个普通文件夹,不做特殊对待。
筛选框只匹配**已经展开过**的名字,占位符里写明这一点 ——
做成「输入即全项目搜索」就得先把整棵树读进内存,正是上面要避开的事。

**内容区** —— 头部是 `‹ 返回`、文件名、路径面包屑、`✕ 关闭`,下方工具条提供预览/源码及放大/恢复分栏。
返回回到树,关闭收掉整栏,**确认之后按当初点的那一颗走**。

- Markdown 默认阅读预览,复用安全 Markdown 渲染器,正文自动换行、最宽 720px 并居中。
  源码视图保留行号和缩进,其他文本文件直接显示源码;超宽代码和表格只在局部横向滚动。
- 文件与对话分列,默认文件宽 480px,拖动上限 960px,窗口不足时收缩以保留对话 360px。
  940px 档文件区靠右浮在对话上方,宽度不超出可用工作区域。
- 放大阅读覆盖侧栏外的工作区域,恢复后回到原分栏;不卸载对话、不停止任务、不丢失草稿。
- 改动只用文件名左边那颗点说。底部没有提示条,也没有保存按钮。
- `Ctrl S` 保存。关掉或切走时才拦一次。
- JSON 在**保存前**校验并指出出错行号 —— `settings.json` 写坏会让 Claude Code
  在这个项目里行为异常,而错误往往到下次启动才暴露。
- 二进制(靠前 8KB 里的 NUL 判定)与超过 512KB 的文件直接拒绝并说明原因。

### 可写范围:早期版本的有意收敛

浏览是整个项目,**可写只有 `.claude/` 和项目根的 `CLAUDE.md`**,其余标「只读」。

这是当前阶段刻意划的线:一个聊天客户端不该顺带成为能改任意源码的编辑器 ——
要改代码就让 Claude 去改,那条路有权限卡拦着;人在这里直接改则绕过了那层保护,
成了两套标准。

**后续方向是往 ADE(Agentic Development Environment)走**,那时编辑范围会重新
设计,而不是简单放开开关。在那之前这条线不动。

## 7. 对话区

### 正文

- 对话内容列在主区域内水平居中,最宽 720px;文件栏展开或窗口变窄时随可用宽度收缩。
  正文、思考、工具记录与交互卡共用这一列;下面的左右对齐均指列内,不将正文文字居中。
- **用户消息**靠右、有气泡,最宽 560px,**保持纯文本** ——
  他打的就是他想说的,不该被当标记语言重排。
- **Claude 消息**靠左、无气泡、无署名(左右分侧已经说明谁在说话),最宽 720px,
  **按 Markdown 渲染**:粗体、斜体、行内代码、链接、标题、引用、分隔线、
  列表(含嵌套一层)、表格。
- **代码块**单独成块,带语言标签与复制按钮。聊天里贴出来的代码多半是要拿去用的,
  让人手选容易漏首尾。
- 链接交给系统浏览器,**主进程只放行 http/https**:那个 URL 来自模型输出,
  属不可信输入。

正文只产出元素、不碰 `innerHTML`,所以模型吐出来的 `<script>` 只会被当字面文本显示。

### 思考

Claude 回答前的思考**默认折叠**,露一行摘要;正在思考时自动展开 ——
那会儿屏幕上没有别的东西,看得见它在动比一句「思考中」有信息量。
切走再切回,思考块随历史一起回放,不会消失。
它是过程不是结论,所以灰、窄,不与回答抢注意力。

### 等待态

忙着但还没开口时,给一行:**动着的指示点 · 已用时长 · 本轮输出 token 数**。

- 状态文案取自 SDK 报的 `requesting` / `compacting`,不自己编;API 自动重试
  与撞到额度上限也归到这一行(「网络波动,自动重试中」「额度受限,等待重置」)——
  这两种静默停顿最像卡死,必须说出来;其余一律说「处理中」——
  那时多半在跑工具,而具体跑什么工具行已经写了。
- token 数**不是逐字跳的**(`usage` 只在每条助手消息收尾时出现),
  所以拿到之前不显示,而不是先挂一个 0 假装在数。
- 上下文被压缩时对话流里落一道低调分界(「上下文已在此处压缩」)——
  不留痕的话,「它怎么忘了前面说的」无从解释。

### 工具行

连续的普通工具调用默认合并成一条可展开的“执行记录”,摘要统计实际调用次数,
例如“读取 10 次 · 执行 4 条命令”。执行中显示当前未完成工具的动作;
点击摘要后按原顺序显示工具行,再由各行控制命令/输出/diff 详情。
新增调用和结果回填保持已展开的组。正文、思考、用户消息、待办、交互工具、
失败、中断与带 stderr 的记录划分分组并单独展示;权限和提问卡保持独立。
分组只发生在渲染层,历史记录仍逐项保存和回放。
展开组内的长路径与单行命令换行显示全文,不再截断末尾。

认得的工具有专门形态,认不出的降级成只显示名字 —— 不猜、不硬画。

| 工具 | 形态 |
|---|---|
| Read | 一行标题 |
| Bash | 单行命令内联;多行命令与输出默认折叠,展开后完整展示命令,`$` 只标第一行 |
| Edit / Write / MultiEdit | 共用 diff 形态:入参先合成预览(批准前就看得见改什么),结果的 `structuredPatch` 盖权威版;加删行数,`+/-` 放左侧独立槽位(混在正文里,复制会带上记号) |
| Grep / Glob | 模式 + 范围,结果回来补命中数 |
| Task | 「子 Agent · 类型 · 描述」—— 不画的话,子 Agent 在界面上完全不可见 |
| TodoWrite | 同一会话只保留一张卡、原地更新,正在做的那条带呼吸点 |

对话中的多行命令与 diff 默认只显示工具标题,由“展开 / 收起”控制详情。
待批准权限卡内的预览默认展开,多行命令不截断:一条 `cd` 加三个 `grep`,
真正改动机器状态的可能是后面几行 —— 要批准一件事,先得看得见它。

工具输出默认折叠;展开后超过 16 行时先显示前 16 行,可点击“展开全部”或收回预览。
展开的多行命令与输出都随内容撑高,不设置内部纵向滚动条;展开后的命令完整展示。

`stderr` 与中断走警示色的**前置横线**,不做红框:它是过程,不是失败。
工具真失败了(tool_result 带 is_error)则统一在行尾标「失败」;
Bash / Edit 的失败并入警示左线。

### 行内卡片

都出现在对话流末尾,**不是弹窗** —— 弹窗会遮住上文,而要看的正是上文。

四种要人作答的卡(权限 / 计划 / 反问 / MCP 表单)各自排**队列**,一次只画队头,
答完一张顶上下一张 —— SDK 会并发扇出工具调用,单槽会把先到的卡顶掉,
被顶掉那张永远无人作答,整轮就卡死。权限卡有排队时在标签行注明「还有 N 个在排队」。
上游取消(打断)的请求由主进程发 dismiss 把对应卡收走;切会话清空全部队列。

| 卡片 | 何时 | 要点 |
|---|---|---|
| 权限请求 | 工具需要批准 | 陶土左条 = 在拦你。标题优先用 CLI 桥接层写好的整句提示,没有才由工具名 + 最该看的参数拼;改文件的批准直接给 diff 预览(复用工具行),`decisionReason`/`blockedPath` 有就显示;「本次会话内不再问」只在 CLI 给出规则建议时出现,按钮上写明放行范围(如 `Bash(ls:*)`),不是整个工具名 |
| 计划卡 | `ExitPlanMode` | 沙绿左条 = 在等你满意 |
| 反问卡 | `AskUserQuestion` | 分步:进度、选项、可加补充说明、「都不合适我直接说」。**选中不等于提交**,提交是独立按钮 |
| MCP 表单 | `onElicitation` | 按 JSON Schema 通用渲染;头部写清是哪个 MCP 服务在要 —— 说话的不是 Claude |
| MCP 面板 | `/mcp` | 按来源分组、状态与工具数,可展开工具清单、启停、重连;缺授权的服务给「授权」入口(重连解决不了缺授权) |
| Agent 面板 | `/agents` | 名字、描述、所用模型 |

权限确认卡的操作区分两行:第一行“允许 / 拒绝”固定横排、不收缩、不折行,按钮高度至少 44px;第二行仅在有规则建议时显示“本次会话内不再问”按钮,左对齐、完整显示授权范围并按宽度换行。标题、命令、说明与范围外路径不撑出卡片,亮暗主题和窄内容区均适用。此排版仅作用于权限卡,不改变共享操作行、其他卡片或审批语义;保留按钮原有键盘焦点及 Enter/Space 操作。

### 滚动

对话流只有一条纵向主滚动条。普通正文、路径、思考与 diff 长行自动换行,
消息不撑出对话区;超宽代码块与表格保留各自必要的横向滚动。
主滚动条预留槽位,避免出现或消失时正文宽度跳动。

**只在本来就贴着底时才跟**(留 24px 余量)。往回翻着读的时候被拽回底部,
比不跟更烦。判定盯的是 DOM 变动而不是数据变化 ——
正文长高不一定经过状态:代码块换行、等待态那行字变长、Markdown 收尾重排都会顶高内容。

换会话时重新贴底:载入的是另一段历史,该看见最后一条。
上翻时在对话区右下角显示“回到最新”,点击后滚到底并恢复跟随;按钮不占消息流空间。

### 空态与错误

空态:居中的“今天想做些什么?”衬线标题与项目读写提示,不编造用户姓名;不加无实现的快捷功能卡。
错误:一行醒目但不惊悚的文本,不用弹窗。

## 8. 输入区与控件条

输入框与控件条合成同一张卡,控件在卡内底部 —— 都是「发这条之前要决定 / 要知道的事」,
所以手和眼都在输入框上,不放顶栏。

输入卡采用 20px 圆角、轻描边与极淡阴影;聚焦仅强调描边,不增加额外轮廓。发送为 32px 上箭头按钮,忙碌时原位显示停止方块,保留“发送 / 停止”无障碍名称与悬停提示;权限和努力控件减轻容器感,警示语义保持。

输入卡与对话内容列同宽(最宽 720px),左右边缘对齐;两处共用侧边留白,
输入区扣除对话主滚动条的 8px 预留槽位,命令面板跟随输入卡宽度。
窗口变窄或文件栏展开时两者一起收缩,不改变输入和控件弹层行为。

回答进行中 Enter 照样能发:消息**排队**,当前轮答完接着处理,输入不再被吞掉
(占位文案会说明)。可以直接**粘贴图片**:缩略图排在输入框上方,发送前可逐张移除,
消息气泡上标「图 ×N」。

```
┌──────────────────────────────────────────────────────┐
│ 给 Claude Code 发消息…(Enter 发送,Shift+Enter 换行) │
│                                                      │
│ ⊙ 询问 ▾   ◔   ⌸                Opus   高   [ 发送 ] │
└──────────────────────────────────────────────────────┘
```

| 控件 | 形态 |
|---|---|
| 权限 | 胶囊 + 弹层。四档:询问 / 自动接受编辑 / 计划 / 完全放行。`完全放行` 带警示视觉。计划与完全放行**不跨启动**,重开回到询问档 —— 危险档必须每次亲手再选 |
| 上下文 | **环形**,点开是分类明细(消息 / 系统工具 / MCP 工具 / Skill / 记忆文件各占多少)+ 额度两条 |
| 子进程 | 有后台任务时才出现的胶囊,可展开、单独停止、转入后台 |
| 模型 | 纯文字、不画容器,只显示第一个词;弹层给完整名与 SDK 提供的说明 |
| 努力 | 只显示一个中文字;弹层是可拖的停靠滑块 |
| 发送 | 输出中整颗变「停止」,同一个位置的互斥状态,不另设按钮 |

**上下文为什么从归属行挪过来**:百分比只说明快满了,说明不了该删什么;
而它和权限、模型、努力同属「发这条之前要知道的事」,不该单独待在屏幕另一头。

**努力滑块的两个要点**:整条轨道接管指针事件(点落在两个点之间也要响应);
拖动只动预览、松手才提交 —— 拖过五档只发一次切换。切换经 flag 设置层原地生效,
对话不中断,和切模型同级。
模型不支持努力程度时(`supportedEffortLevels` 缺席,如 Haiku)整个控件禁用,
而不是画五个点让人点了不生效。

**附件**:控件条左侧增加有可访问名称的 SVG 附件按钮;输入卡接收文件拖放。附件卡在文本框上方自动换行,文件名单行省略并保留完整 title,展示类型/大小及处理错误,不会撑宽输入卡。图片用缩略图,文档用 SVG 文件图标;预览与移除是独立键盘按钮,附件预览支持 Esc、遮罩关闭、焦点限制及焦点恢复。超过 10,000 字符的单次文本粘贴转为 TXT 卡,可“放回输入框”,不吞掉原文和已有草稿。处理中不能发送;附件草稿按会话隔离,发送后的气泡只展示文件卡而非文档全文。PDF 的预览说明使用 Read 工具,Office 预览仅为提取文字而非原始排版。沿用现有亮暗主题 token,不增加横向滚动。音视频入口暂不开放。

图片缩略图与大图预览需实际加载成功;CSP 仅对图片开放 `data:` 来源,不放宽脚本或其他资源权限。保持原有卡片尺寸与布局,PNG/WebP 回归同时核对解码尺寸和预览显示,不以存在 `<img>` 标签代替加载成功。

**命令面板**:行首第一个字符是 `/` 时弹。列表由 SDK 运行时提供,按来源分三组,
**按相关度排序**:名字全等 > 别名全等 > 名字前缀 > 别名前缀 > 名字包含 > 别名包含 >
描述包含。分组只作同分时的次序 —— 反过来的话,一条只在描述里蹭到关键词的内置命令
会压过名字前缀就对上的项目命令。

命令列表只有纵向滚动,宽度跟随输入卡且不被内容撑开。命令名优先显示,描述保持单行,超出可用宽度用省略号;极长命令名、参数提示与别名也可省略,悬停显示各字段全文。省略仅作用于展示,过滤、相关度排序和命令填入均使用完整原始数据;保留 ↑↓ 选择、选中项滚入视野、Enter 确认、Esc 取消。

`/model`、`/effort`、`/mcp`、`/agents` **由界面接管**,不发给 agent:
这些在终端里也是 CLI 界面层自己处理的,发过去不会有任何反应。

## 9. 贯穿全局的规则

**陶土用于少量强调**:主按钮、打开的文件入口、分支与等你决定的卡片;当前会话采用中性底 ——
这条有自动断言盯着,因为它最容易被 CSS 优先级悄悄盖掉,肉眼几乎看不出来。

**拿不到的数据就不画。** 额度接口在 API Key / Bedrock / Vertex 会话下报
`available: false`,那一整块就消失 —— 不留空槽、不写「未知」、
不画一个可能不准的百分比。

**深色是一等公民。** 任何新组件必须同时给出亮色与深色取值,并进对比度检查:
根元素的 `color-scheme` 同步当前主题,原生控件和代码块滚动条不出现亮暗错配。
≤14px 文字 ≥4.5:1,非文字标记 ≥3:1。深色不是浅色的反色 ——
主色与警示色要提亮。规格里的取值若不达标就改取值,不放宽下限。

**图标一律内联 SVG。** 打包的四套拉丁字体不含几何字形,用字符会渲染成豆腐块。
画的时候留出画布余量:齿轮那一版手写路径有坐标跑到 `0` 以外,左边被裁掉了。

**一次只有一个会话是活的。** 切会话会关掉前一个。切走时旧会话的残留事件
一律丢弃,否则上一轮的回答会接在新会话下面。

**渲染层传来的路径一律不可信**,在主进程做硬性收敛,越界直接拒绝。

## 10. 已定死的接口约束

画稿时不要绕开:

1. **模型列表是动态的**,数量与名字由运行时决定,不能把某个具体型号画进版式当装饰。
   最长一项通常是 `Default (recommended)`。
2. **努力恰好 5 档**(`low` / `medium` / `high` / `xhigh` / `max`),但**并非每个模型都支持**。
3. **权限恰好 4 档**。
4. **会话按目录分桶**,切项目 = 整列换一批。
5. **切模型、切权限、切努力都是瞬时的原地控制请求**,不需要过渡态。
6. **路径截断规则**:保留盘符与末两级,中间 `…`;末两级超过 44 字符时从末级中间截,
   因为末级是项目名,掐头会认不出。

## 11. 当前边界

- 图片大图使用铺满窗口的模态查看器而非附件标题卡;背景以主题底色半透明覆盖并轻度虚化,中心画布按比例适应窗口,顶栏保留名称/缩放/下载/关闭,44px 操作区。正文右侧更多按钮悬停/聚焦出现并保留占位,触屏常显;预览图右侧常显。菜单含添加到聊天/复制图片/从资源管理器打开/下载副本,收敛到可见窗口,支持上下键/Home/End/Esc与焦点返回。缩放后只画布滚动,菜单与顶栏固定;窄屏操作不挤出窗口。读屏反馈成功/失败,忙碌时禁止重复提交。添加只进入附件草稿,不发消息;本地定位保持项目真实路径边界,另存副本拒绝覆盖原图。
- Markdown 图片在正文列内按原比例展示,高度最大 420px,右侧预留 52px 菜单空间,不产生额外横向滚动。加载/失败使用主题中性卡片并保留图片说明;网络图片需主动点击加载,不自动访问第三方。图片按钮有明确预览名称和焦点状态,大图使用全窗口查看器,支持关闭按钮/Esc/背景关闭与焦点返回。只读取已登记项目内、真实路径未越界且不超过 20MB 的 PNG/JPEG/GIF/WebP;Markdown 文件内相对引用按文件所在目录解析,不开放系统路径或执行协议。
- 当前查看会话的渠道拒绝工具图片结果时,输入区上方使用现有 notice 样式短暂显示兼容提示(支持读屏状态播报),明确图片未交给模型读取、视觉判断需换渠道。显示 5 秒后自动消失,连续触发重新计时;切换时立即清空并取消计时,切回/历史回放不重弹旧提示。保留模型端未读取说明,不阻塞回答、不伪装成模型正文、不另开弹窗。
写在这里的都不是缺陷,是明确的取舍或已知限制:

| 事项 | 现状 |
|---|---|
| 文件编辑范围 | 只有 `.claude/` 与根 `CLAUDE.md`。早期版本有意收敛,后续往 ADE 方向重新设计 |
| 搜索 | 只搜会话标题与首句。搜正文要把每个会话全文读进内存 |
| 安装包签名 | 未签名,首次安装会有 SmartScreen 提示。只有代码签名证书能解决,没有软件层面的绕法 |
| 平台 | 仅 Windows |
| 额度 | 实验性接口,部分会话类型拿不到 |

## 12. 怎么验收

规格里的规则大多有可执行的对应物,改了界面而这些挂了,说明其中一方错了:

| 层 | 盯什么 | API |
|---|---|---|
| `npm run unit` | 路径截断、Markdown 解析、命令排序、列宽夹逼、路径收敛 | 否 |
| `npm run contrast` | 两套主题的对比度下限 | 否 |
| `npm run measure` | 关键尺寸对齐 token、三档宽度不塌、侧栏操作保持中性 | 否 |
| `node scripts/chat-appearance.mjs` | 模拟会话的亮暗/三档布局、图标发送停止、工具折叠、附件与文件栏截图 | 否 |
| `node scripts/settings-dialog.mjs` | 隔离设置的分类/布局/保存失败与重试/密钥语义/更新状态/焦点和关闭 | 否 |
| `node scripts/markdown-images.mjs` | 图片解析与路径/IPC/查看器缩放和菜单/复制定位保存替身/原图保护/附件草稿隔离/流式与文档引用 | 否 |
| `npm run e2e` | 点了按钮之后事情有没有真的发生 | 是 |
| `npm run packaged` | 打包产物能不能起、能不能收到回复 | 是 |

`e2e` 支持 `--only N` 只跑某几节。
两条经验写在 [CLAUDE.md](../CLAUDE.md):`waitForFunction` 的超时位容易写错;
**给了宽限的等待不叫断言**。
