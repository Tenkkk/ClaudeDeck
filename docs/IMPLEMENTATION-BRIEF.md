## 1. 视觉语言（一句话）

纸白底、发丝线、6px 圆角、零阴影（只有弹层有）。
Claude 的正文用 Source Serif，界面文字用 Figtree，路径与数字用 IBM Plex Mono。
陶土 `#a75f38` **只出现在三处**：当前项、主按钮、等你决定的卡片。
品牌位用 Caprasimo（只有拉丁字形，中文会回落，所以只用在 `ClaudeDeck` 这个词上）。

两条硬性约束，评审会照着量：

- **≤14px 的文字一律 ≥4.5:1**；非文字标记（圆点、勾选框、分隔线）≥3:1。
  token 表里那五档灰就是按这个反推的，不要往浅调。
- **单选的圆点、勾选框在未选中时也必须看得见**（`--mark #82796a`）。
  「一组可选项」这个信息是靠它们传达的，不是靠选中那一个。

## 2. 相对 DESIGN-SPEC 的改动，以及为什么

每一条都是「原稿这样 → 改成这样 → 因为」。按重要性排。

### 2.1 会话列表从「单目录」变成「项目 → 会话」两层

- **原稿**：屏幕 C 选一个工作目录，切换目录 = 整个左侧列表换一批。
- **改成**：侧栏并列多个项目，每个项目可折叠，会话挂在各自项目下面。
  点别的项目里的会话 = 隐式切换 `activeWorkspace` 再 resume。
  「切换目录」这个动作退休；屏幕 C 变成「选择项目」，只在一个项目都没有时出现。
- **因为**：用户同时开着好几个仓库是常态。上百条会话时按项目折叠比时间分组更好找
  （时间分组回答不了「我上次在 SwitchDeck 里做到哪了」）。
- **工程影响**：偏好里 `workspaces: string[]` 从「最近用过」升级成「项目清单」
  （各带显示名、折叠状态）；`listSessions` 要按项目逐个调用再合并；
  主区必须显示当前会话属于哪个项目（终稿 05 的归属行），否则跨项目跳转会迷路。

### 2.2 模型 / 努力 / 权限 从顶栏搬到输入框下沿

- **原稿**：三个控件在顶部工具栏，右端一个「停止」。
- **改成**：权限在输入框左下，模型和努力在右下；顶栏只剩「项目 / 会话标题 / 上下文%」。
  **「发送」在输出中整颗变成「停止」**，不再另设一个按钮。
- **因为**：这三件事是「发这条消息之前要决定的」，手和眼都在输入框上。
  停止和发送是同一个位置的互斥状态，一个 `busy` 两种渲染，也省掉顶栏那个按钮。
- **注意**：努力档位在控件条上只显示一个字（`高`），点开是停靠式滑轨。
  **仍然是 5 个固定停靠点，不是连续滑块**——规格那条约束没破，只是不把五个词全摊出来。

### 2.3 对话区：用户靠右有气泡，Claude 靠左无气泡，署名全删

- **原稿**：每条消息顶部一行小字署名（`你` / `Claude`）。
- **改成**：左右分侧本身就说明了谁在说话，署名删掉。时间和动作（复制等）
  只在鼠标停在那条消息上时出现；每条下面**常留 20px 空槽**，所以悬停不会让内容跳动。
  正在输出的那条不出动作行（半截文本复制过去没意义）。
- **因为**：署名 + 时间在每条消息上重复，是最容易让「安静的写作工具」变成日志控制台的东西。
- **这一条与规格 §D3 冲突，见第 5 节。**

### 2.4 左下角：工作目录 → 额度与版本

- **原稿**：当前工作目录路径 + 「切换目录」按钮。
- **改成**：两行。第一行 `额度 5 小时 38% | 7 天 61%`，第二行 `0.1.0 · CLI 1.0.62 · 本会话 $0.11`。
  重置时间和 7 天 Opus 额度进悬停卡。点版本行出主题菜单（终稿 16）。
- **因为**：项目分组之后「当前目录」已经写在归属行上了，重复。
  额度是长期使用中真正会想看的数字。
- **不要画进度条**：24px 宽的小条区分不出 38% 和 61%，纯装饰。数字自己够。

### 2.5 新增：`.claude` 读写中栏

侧栏里每个项目名下面挂一个 `.claude` 折叠节点，点文件在侧栏和对话区之间开一栏（320px）读写。
**范围只到 `.claude/` 和项目根的 `CLAUDE.md`**，不做通用文件树——否则就变成半成品编辑器。
改动只用文件名左边一颗陶土点表示，`Ctrl S` 保存，点叉或切文件时才弹 [取消 / 不保存 / 保存]。
JSON 写坏要在保存前拦住并指出行号。940px 时这栏改成盖在对话区上的浮层。

### 2.6 新增：子进程

控件条上一颗胶囊 `● Shell 2 Agent 1 +1`，点开是任务清单，可查看输出 / 停止；
subagent 可以点进它的独立对话再返回。**没有后台任务时整颗消失**，不留空位。

## 4. 五个坑（踩了就得返工）

### 4.1 额度接口是实验性的

方法名自带 `DO_NOT_RELY_ON_THIS_API_YET`；API Key / Bedrock / Vertex 会话拿到的是
`rate_limits_available: false`。
**拿不到就让整块消失**，只留「本会话 $0.11」。不留空槽，不写「未知」，
更不要画一个可能不准的百分比——那比不显示更糟。

### 4.2 只 fork 对话不回退磁盘 = 上下文和硬盘不一致

Claude 已经改过的文件还在改后的状态，分支里的对话却以为没改过，之后 Edit 会开始报错。
所以「同时把文件回退到那一刻」**默认勾上**；没开检查点时禁用并写明原因，不要悄悄跳过。

### 4.3 写不出万能 dialog 渲染器

`dialogKind` 是开放字符串，`payload` 的形状按 kind 各自定义、协议层只当不透明对象转发。
正门是起 query 时用 `supportedDialogKinds` 声明我们会画哪几种——没声明的 CLI 自己按默认处理、
根本不问我们，界面上不会出现半张残废的卡。
万一收到未声明的 kind（版本升级），回 `{ behavior: 'cancelled' }` 并显示终稿 06 里那条低调提示。
**绝不能瞎猜 payload 硬画一个框**——猜错的选择会真的落到文件上。

### 4.4 SDK 的 session store 是唯一事实来源，删不掉已写入的消息

所以没有「重新生成」这回事。界面上那个动作叫「从这里重答 ↳」，
`↳` 在这套界面里只有一个意思：**会多出一条分支会话**。不要做成看起来像原地覆盖。

### 4.5 不要开 `forwardSubagentText`

开了主对话会被两三个子 Agent 的自言自语冲垮。这也是为什么子 Agent 的对话放在独立面板里。

## 5. `DESIGN-SPEC.md` 需要改的三处

改完再动手，否则你会照着过时的描述实现。

1. **§D3「Claude 消息顶部一行小字署名 `Claude`」** → 删掉。
   左右分侧 + 悬停元数据之后这行字是纯冗余。
2. **§4.4「会话按工作目录分桶。切换目录 = 整个左侧列表换一批」** → 改成

3. **屏幕 C 的定位** → 从「选择工作目录」改成「选择项目」，

## 6. 起 query 时必须打开的开关

```ts
enableFileCheckpointing: true,            // 不开，分支就无法回退文件（坑 4.2）
toolConfig: {
  askUserQuestion: { previewFormat: 'html' },  // 不开，选项预览渲染不出来
},
supportedDialogKinds: [ /* 只写我们真的会画的 */ ],
askUserQuestionTimeout: 'never',          // 图形界面里人会切走去干别的
forwardSubagentText: false,               // 保持关闭（坑 4.5）
```

前三个不开，终稿里对应的画面永远出不来。

## 7. 实施顺序

一次做一层，每层做完能看见东西，不要并行铺开。

1. **token 层**：抄第 01 节进 `styles.css`，删掉所有占位样式。
2. **骨架**：屏幕 A / B / C / D 四个空壳 + 三段式布局 + 侧栏项目分组（先写死假数据）。
3. **接上真数据**：`listSessions` 按项目合并、归属行、上下文百分比、额度两行、版本号。
4. **对话区**：气泡左右分侧 + 悬停动作行（先只做「复制」）+ 流式光标 + Read/Bash/Edit/TodoWrite 四种工具行。
5. **控件条**：权限 / 模型 / 努力三个弹层 + 发送⇄停止。切 Effort 要有几百毫秒的过渡态，不能看起来像卡死。
6. **要你点头的卡**：权限卡 → AskUserQuestion 分步卡 → 计划卡 → MCP 表单。
7. **剩下的**：斜杠命令面板、`.claude` 中栏、子进程面板、分支与文件回退、右键菜单。
8. **深色**：换一个 `:root[data-theme="dark"]` 块，布局代码一行不改。

## 8. 验收时按这些量

- token 表里没有的色值，代码里一个都不许出现。
- 任意 ≤14px 的文字，前景/背景对比 ≥4.5:1；未选中的圆点和勾选框 ≥3:1。
- 940 / 1200 / 1600 三档下：无横向滚动、模型名不折行、「停止」不换行。
- 悬停任意一条消息，下面的内容不发生位移。
- 拔掉网络：限流卡、安装失败态、未知 dialogKind 提示都能正常出现，且都不是白屏。
- 用 API Key（非订阅）跑一次：额度那一行整块不出现，只剩版本和花费。
- 切一次 Effort：界面有过渡态，对话不丢，会话 id 不变。
- 点一次「从这里重答」：出现分支确认 → 侧栏多一条缩进的分支 → 原会话内容不变。
